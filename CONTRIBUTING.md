# Contributing

TrustLock is a team project by Agoro Oluwatimilehin (Timi), Brayan Sorgho and Mikezx8 (see README, Team and responsibilities).

1. Read `AGENTS.md` and `docs/architecture.md` before writing code.
2. Never commit `.env` or a key file.
3. Contract changes ship with a test for the new panic path.
4. Keep the README's "do X, see Y" steps true. If a command cannot work yet, mark that step as stubbed rather than pretending.

Coding agents: follow the build order in `AGENTS.md`. Do not open pull requests against random remotes or push without Timi asking.
